
# Smart Microgrid Simulation

### Interactive Renewable Energy Systems Modelling

**Developed by Shahed Khan Labib**

[Launch Live Simulation](https://shahed2710.github.io/smart-microgrid-simulation/)

## Project Overview

An interactive, browser-based educational simulation
demonstrating energy balancing in a grid-connected
renewable energy microgrid.

The model combines solar PV, wind generation,
battery energy storage, electricity demand and
grid import/export over a 24-hour period.

## Engineering Objectives

- Simulate solar and wind energy generation
- Analyse hourly electricity demand
- Model battery charging and discharging
- Calculate electricity import and export
- Evaluate renewable energy utilisation
- Explore different system configurations

## Technologies

HTML5 | CSS3 | JavaScript

## Simulation Features

- Adjustable solar PV capacity
- Adjustable wind turbine capacity
- Variable electricity demand
- Configurable battery energy capacity
- Interactive hourly power charts
- Automatic energy performance calculations

## Engineering Model

Simulation interval: 1 hour

Battery initial state of charge: 50%

Battery charging efficiency: 95%

Battery discharging efficiency: 95%

Maximum battery charging/discharging power: 0.5C

Generation and demand use illustrative profiles.
Grid exchange is assumed unconstrained.

The current model does not simulate network voltage,
frequency, power losses or protection coordination.

## Running the Project

1. Open the live simulation link above.
2. Adjust the system configuration sliders.
3. Observe changes in energy performance.
4. Compare hourly generation and demand profiles.

Alternatively, download the repository and
open index.html in a modern web browser.
